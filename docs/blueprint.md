# **App Name**: Unimax AI Studio

## Core Features:

- AI Chat: Central AI Chat: Ayush Unimax AI answers questions based on user-provided text, images or mixed inputs, as a tool to help people better communicate. A Deep Research toggle incorporates comprehensive context.
- Iterative AI Content Generation: Iterative AI Maker: Input a single prompt, such as `A painting of a dog`, or `make it more futuristic`, to progressively make adjustments using generative AI tools.
- Generative Text Tools: Text Generation Suite: Prompt AI to create stories, documents, ads, code, summaries and more, powered by an AI tool. Export results directly or load results into AI Chat.
- AI Translation: Translation tool that can translate any arbitrary user provided text using an AI tool.
- AI Song Composition: Compose songs complete with lyrics and music using AI powered tool
- App Creation from Boilerplate: Scaffold apps, websites and games with a simple starting boilerplate.
- Simple File Generation: Quickly produce text-based files like code, .txt, markdown or json.

## Style Guidelines:

- Primary color: HSL(220, 53%, 47%)  which is equivalent to #4285F4. This will be used to maintain brand consistency and highlight primary interactive elements like buttons and active states.
- Background color: HSL(210, 22%, 90%) which is equivalent to #E2EAF2. A light background helps create a clean and modern look, suitable for extended use and readability.
- Accent color: HSL(190, 68%, 45%) which is equivalent to #34A853. It offers a harmonious yet distinct contrast, suitable for secondary actions or visual cues.
- Headline font: 'Space Grotesk', sans-serif, for a modern, tech-forward feel
- Body font: 'Inter', sans-serif, to complement the headlines with a clean, readable style
- Lucide icons used throughout, for a simple, consistent, modern look
- Spacious, card-based layouts to clearly distinguish areas and improve information accessibility.
